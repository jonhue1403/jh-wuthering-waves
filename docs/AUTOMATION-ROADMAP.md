# CORE_AND_ROUTES delivery roadmap

This execution stops at CORE_AND_ROUTES. Echo-management expansion, endgame,
additional events, arbitrary exploration and Android remain later scope.

| Delivery boundary | Offline implementation | Release/qualification gate |
| --- | --- | --- |
| A: upstream/session/resource foundation | Integrated upstream master; inherited input guard, cancellation, policy/journal, explicit controls | Live matching-privilege pause/takeover/held-input cleanup |
| B: material goals/daily/weekly coordination | Cultivation adaptation; bounded shared queue and actual inventory observers; current Weekly Activity gate | Real account/server/reset/source/reward profiles; no unresolved spending |

| First useful release review | Core source plus single-camp runtime qualification mechanism | Single-camp requalification on 3.0.4, eligible repeated sessions, independent evidence review |

Implementation/independent source review does not waive these live gates.
No real story segment, source mapping or route is fabricated to mark a row done.
Complete all offline work, then follow [the local qualification sequence](LIVE-QUALIFICATION.md).
